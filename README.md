# EduNext - School Management System

EduNext is a web-based School Management System developed using Java, JSP, Servlets, JDBC, MySQL, HTML, CSS, and JavaScript. The project is designed to manage various academic and administrative activities through an interactive dashboard interface.

## Features
- Student Dashboard
- Teacher Management
- Attendance Management
- Homework System
- Timetable Management
- Examination & Marks System
- Fee Management
- Dynamic Database Connectivity
- Responsive UI Design

## Technologies Used
- Java
- JSP & Servlets
- JDBC
- MySQL
- Apache Tomcat
- HTML/CSS/JavaScript
- Eclipse IDE

## Database
Database used:
teacher_web

SQL file included for database setup.

## Software Required
- Java JDK
- Eclipse IDE Enterprise Edition
- Apache Tomcat 9
- MySQL Server
- MySQL Workbench

## Setup Instructions
1. Import the project into Eclipse.
2. Configure Apache Tomcat server.
3. Import the database file into MySQL.
4. Add MySQL JDBC Connector.
5. Run the project on Tomcat server.
